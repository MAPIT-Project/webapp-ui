## Tech Stack

**Frontend**  
- Svelte 5 (SvelteKit)
- Typescript
- Tailwind CSS

**Backend**
- Node JS
- SvelteKit
- Drizzle ORM

**Database**
- Supabase (PostgreSQL)

## General Info

 **Schema**  
 All tables are created with *created_at* and *updated_at* columns. These columns contain a timestamp in the UTC timezone.
